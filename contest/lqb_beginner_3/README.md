📝 个人复盘与解题历程

1. 社团出游 (club_outing.cpp)

· 我的初步思路：倒序剔除思路。先按游玩费用从小到大排序，从最贵的同学开始剔除，直到游玩费用 + 租车费用 <= 预算 B。
· 踩过的坑：
  1. 运算符优先级翻车：向上取整时写了 (N_max+K-1/K)，结果 1/K 先算变成了 0，实际变成了 (N_max+K)*C，导致车费算错。
  2. 逻辑写反：while 条件写成了“预算够就删人”，程序行为与预期完全相反，输出了初始下标。
  3. 致命的数据溢出（血泪教训）：只把 B 改成了 long long，漏改了 int C。导致 人数 * C 突破了 int 上限，条件判断失效，循环提前退出。
· 最终正确写法：
  · 修正向上取整公式为 ((人数) + K - 1) / K * C（并给整体加上括号）。
  · 无脑 long long：将 C 和 B 全部改为 long long，彻底解决溢出问题。

2. 迎新配送 (welcome_delivery.cpp)

· 我的初步思路：贪心。先读入所有距离，按从小到大排序。让最远的留在最后，其他的往返，最后加上最远的单程。
· 踩过的坑：
  1. 执行顺序颠倒：在 sort 之前就求和，导致求和的数据是乱序的，并没有把最远的剔除。
  2. 循环边界写错：循环写成了 i < N - 2，把倒数第二个数也漏掉了，导致少算了一栋楼的距离。
  3. 数组越界：写了 D[N] 试图访问最远距离，但数组下标有效范围是 0 到 N-1。
  4. 计算溢出：总路程可达 $10^{14}$，起初用 int 存不下。
· 最终正确写法：
  · 先 sort 排序，用 D[N-1] 取最大值。
  · 循环条件改为 i < N - 1。
  · 公式 long long ans = D[N-1] + 2 * sum; 完美处理。

3. 讲义补印 (Handout_reprint.cpp)

· 我的初步思路：奇偶分类讨论。通过 L 和 R 的奇偶性，判断涉及首尾的哪一面，套用公式算纸张数。
· 踩过的坑：
  1. 硬编码正常页数：用纸张数直接乘 2 再减固定值去算正常页数，没有考虑到重印范围过大时正常页数是动态变化的，导致样例都过不了。
  2. 边界缺失：漏掉了“总页数 N 为奇数时，最后一张纸背面是空白”的情况。
· 最终正确写法：
  · 保留我的奇偶分类公式算 paper。
  · 动态计算正常页数：正常页数 = 总重印页数 - 本来印错的页数(R-L+1)。
  · 处理边界：if (N % 2 != 0 && R == N) total_pages -= 1;（减去空白背面）。

4. 社团合影 (club_group_photo.cpp)

· 我的初步思路：由于要求身高差不能超过 K，先对身高排序，问题转化为找最长的连续子数组。
· 难点突破：
  1. 初次接触滑动窗口，对 ans = max(ans, right - left + 1) 感到困惑，不理解为什么要“打擂台”。
  2. 后来明白：窗口是动态变小的，ans 必须作为“历史最高纪录”的擂主，否则最后输出的只是最后一个窗口的长度。
· 最终正确写法：
  · 排序 + 双指针滑动窗口。右指针不断右移，一旦身高差大于 K，左指针右移收缩。每次循环都用 max 更新最长合法区间。

5. 彩带拆除 (ribbon_remove.cpp)

· 我的初步思路：枚举拆除位置，每次滑动窗口后，把窗口外的数收集组成新数组，再遍历新数组检查是否有递减部分。
· 踩过的坑：
  1. 运行超时 (TLE)：每次滑窗都重新构造 new_A 并全量扫描，复杂度 $O(N^2)$，在 $10^5$ 数据下超时。
  2. Vector 未清空：new_A 定义在循环外，没写 clear()，导致数据疯狂追加。
  3. 越界与多减：循环边界写错导致越界；用 ans-- 在遇到多个递减时会多减。
· 最终优化（重要思维转变）：
  · 空间换时间：不再构造新数组，而是预处理出 pre_ok（前缀是否非递减）和 suf_ok（后缀是否非递减）数组。
  · 拆掉窗口后，只需 $O(1)$ 判断：前缀合法 && 后缀合法 && A[L-1] <= A[R+1]（交界处非递减）。
  · 成功将复杂度降至 $O(N)$。

🏆 全局避坑与经验法则（牢记！）

1. 数据溢出防范守则：
   · 题目数据范围 $\ge 10^9$，或者涉及变量相乘，必须使用 long long。不要抱着“这个数本身不大”的侥幸心理（如 int C 虽然只有 $10^9$，但乘上 $10^5$ 的人数就会溢出）。
   · 向上取整公式 (a + b - 1) / b，使用前必须给整体加括号，防止运算符优先级踩坑。
2. 数组与循环安全守则：
   · 只要循环体里出现了 a[i+1]，循环条件必须是 i < 数组长度 - 1。
   · 数组下标有效范围是 0 到 N-1，绝对不要访问 a[N]。
   · 使用 vector 收集数据时，注意是在循环内还是循环外，循环外必须 clear()。
3. 算法复杂度意识：
   · 看到 $N \le 10^5$，警惕 $O(N^2)$ 会 TLE。
   · 遇到需要频繁判断“删掉某一段后，剩余部分是否合法”，优先考虑前缀/后缀预处理 + $O(1)$ 查询，把时间复杂度降维到 $O(N)$。
4. 代码规范与命名：
   · 告别 1.cpp、2.cpp，使用有意义的英文文件名（如 club_outing.cpp），方便赛后复习。
   · 多写注释，特别是复杂的推导逻辑（如奇偶分类公式、滑动窗口的边界），好记性不如烂笔头。
