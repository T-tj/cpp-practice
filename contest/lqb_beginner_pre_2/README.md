## 📂 题解列表

### 1. [宿舍签到](./a_dorm_checkin.cpp)
- **题目说明**：N 名新生，每张表 K 行，求最少需要的签到表数量。
- **核心算法**：数学模拟
- **代码思路**：
  直接判断能否整除。如果 `N % K != 0`，说明有余数，需要额外加一张表，输出 `N / K + 1`；否则刚好整除，输出 `N / K`。
- **注意**：数据范围 \(N, K \le 10^9\)，结果最大可达 \(10^9\)，**必须使用 `long long`**。

### 2. [学习小组](./b_study_group.cpp)
- **题目说明**：N 个学生排成一排，求连续 K 个学生做题总数的最大值。
- **核心算法**：滑动窗口
- **代码思路**：
  1. 开一个 `long long` 数组存储 N 个学生的练习题数，防止后续累加溢出。
  2. 先计算前 K 个元素的和 `sum`，并将其设为初始最大值 `max_sum`。
  3. 从第 K 个元素开始遍历到 N-1：每次向右滑动一位，`sum += a[i]`，并减去离开窗口的 `a[i - K]`，再更新 `max_sum`。
  4. 时间复杂度优化至 \(O(N)\)。
- **注意**：单个数最大 \(10^9\)，K 最大 \(10^5\)，累加和可能会超过 `int` 上限，**务必用 `long long` 存答案**。

### 3. [图书归位](./c_book_return.cpp)
- **题目说明**：书架上乱序排列，每次只能交换第 1 和第 3 个位置的书，求最少交换次数或输出 -1。
- **核心算法**：奇偶性判断 + 分治求逆序对
- **代码思路**：
  1. **奇偶性判断**：因为每次交换位置差 2，所以奇数只能呆在奇数位置，偶数只能呆在偶数位置。遍历数组，如果发现 `i % 2 != A[i] % 2`，说明无法归位，直接输出 `-1` 并结束程序。
  2. **分治提取**：通过 `odd[odd_x++]` 和 `even[even_x++]` 将原数组拆分成奇数序列和偶数序列。
  3. **求逆序对**：因为 N ≤ 2000，数据量很小，直接用两层 `for` 循环分别计算奇数序列和偶数序列的逆序对数量（即冒泡排序所需的交换次数）。
  4. 将两者的逆序对总数相加，就是最终的最少操作次数。
